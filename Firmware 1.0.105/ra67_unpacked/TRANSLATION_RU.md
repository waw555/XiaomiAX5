# Русская локализация Xiaomi AX5 RA67

**Версия локализации:** `1.0.105-ru.3`

**Базовая прошивка:** Xiaomi AX5 RA67 `1.0.105`

## Структура

Оригинальная файловая система в каталоге `rootfs` не изменена. Все файлы
русской локализации находятся отдельно в каталоге `translation_ru`, где
полностью сохранены пути относительно корня файловой системы прошивки:

- `translation_ru/www` — HTML и локализованные webpack-пакеты современной панели;
- `translation_ru/usr/lib/lua/luci/view` — переведённые шаблоны LuCI;
- `translation_ru/usr/lib/lua/luci/view/web/inc/agreement_RU.htm` — соглашение;
- `translation_ru/usr/lib/lua/luci/view/web/inc/privacy_RU.htm` — политика
  конфиденциальности.
- `original` — оригинальные файлы прошивки, которые заменяет перевод; пути в
  каталоге полностью совпадают с путями относительно корня файловой системы.

## Установка переводом «папка на папку»

Из каталога `ra67_unpacked` скопируйте содержимое папки перевода поверх папки
`rootfs` с заменой совпадающих файлов:

```sh
cp -a translation_ru/. rootfs/
```

Оригинальные файлы в репозитории остаются нетронутыми до выполнения этой
команды. Старые webpack-пакеты можно не удалять: локализованные `main.html` и
`init.html` ссылаются только на новые пакеты, а неиспользуемые файлы не влияют
на работу интерфейса.

## Откат переводом «папка на папку»

Чтобы вернуть оригинальный интерфейс, скопируйте содержимое каталога
`original` поверх целевой файловой системы с заменой совпадающих файлов:

```sh
cp -a original/. rootfs/
```

Каталог содержит точные копии из базовой прошивки `1.0.105` только для тех
путей, которые заменяются переводом. Добавленные локализацией файлы с новыми
именами (webpack-пакеты, `agreement_RU.htm` и `privacy_RU.htm`) могут остаться в
файловой системе: восстановленные оригинальные точки входа на них не ссылаются.

## Что локализовано

- первоначальная настройка, вход и обзор сети;
- Wi-Fi, WAN/LAN, DHCP, VPN, QoS, UPnP, DDNS и NAT/DMZ;
- обновление, сброс, диагностика и системные диалоги;
- классические LuCI-страницы и страницы режима точки доступа;
- пользовательское соглашение и политика конфиденциальности.

## Проверка

Из каталога репозитория выполните:

```sh
python3 "Firmware 1.0.105/ra67_unpacked/check_translation.py"
```

Проверка контролирует версию, отдельное расположение перевода, наличие точек
входа и всех файлов, на которые они ссылаются, а также комплектность и точное
соответствие файлов отката оригиналам из `rootfs`.

Для получения прошиваемого образа примените перевод к копии `rootfs`, а затем
упакуйте её штатными для RA67 инструментами с сохранением прав, символических
ссылок и формата разделов. Перед прошивкой сохраните резервную копию и
проверяйте собранный образ на тестовом устройстве.
